# radio-music

Консольная программа на C# (.NET), которая скачивает почасовые записи эфира трёх радиостанций с ru.volna.top и хранит их за последние несколько дней.

## Станции

- Radio Cafe
- Хорошее Радио
- Русский Рок

## Что делает

- Качает последние 23 завершённых часа для каждой станции (текущий час пропускается, он ещё записывается).
- Время считается по Москве: сервер хранит слоты по московскому часу.
- Проверяет уже скачанные файлы (размер и заголовок mp3), битые удаляет и качает заново.
- Скачивает во временный `.tmp` и переименовывает в `.mp3` только после успешной проверки, до 3 попыток на файл.
- Удаляет папки старше `KeepDays` дней.
- Пишет лог в `D:\radio-music\log.txt`.

## Структура файлов

```
D:\radio-music\radio\<Станция>\<yyyy-MM-dd>\<HH>-00.mp3
```

## Настройки (константы в `Program.cs`)

| Константа | Значение | Назначение |
|---|---|---|
| `OutputDir` | `D:\radio-music\radio` | Папка с записями |
| `LogPath` | `D:\radio-music\log.txt` | Файл лога |
| `HoursBack` | 23 | Сколько последних часов качать |
| `KeepDays` | 3 | Сколько дней хранить |
| `MaxAttempts` | 3 | Попыток на файл |
| `MaxParallel` | 4 | Одновременных загрузок |
| `MinValidSize` | 1 МБ | Минимальный размер валидного файла |
| `CheckMp3Header` | true | Проверка заголовка mp3 |

## Запуск

1. Собрать проект (`dotnet build -c Release`).
2. Запустить `radio-music.exe` вручную или добавить в Планировщик заданий Windows.

Рекомендуется запускать **раз в час** (триггер с повтором каждые 1 час): сервер хранит для каждого часа только последнюю запись, и при каждом запуске докачивается только новый завершившийся час.

## Лог

- `[+]` скачан
- `[=]` уже есть, пропущен
- `[~]` файл повреждён, перекачивается
- `[!]` / `[x]` ошибка попытки, будет повтор
- `[FAIL]` все попытки исчерпаны, следующий запуск попробует снова

Код выхода: `0` без ошибок, `1` если были неудачные загрузки.

## Если соединение обрывается

Сервер может разрывать подключение при большом числе параллельных загрузок. Уменьшите `MaxParallel` до 1-2.
